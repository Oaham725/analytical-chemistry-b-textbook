# 分析化学 B · 生命科学学院线上教材

面向一年级生命科学学生的连续阅读教材。当前第一卷包括：

- 第一章：绪论——基本概念、完整分析过程、分析史与生物学证据。
- 第二章：有效数字与测量结果——读数、修约、运算、稀释、重复测量、不确定度与科研诚信。
- 拓展：化学计量学与 AI——校准、多变量信息、PCA/PLS、数据泄漏与模型验证。
- 可追溯的参考书目、原始论文和计量规范。

## 文件组织

`manuscript/` 为可编辑教材原稿，`assets/` 为样式与目录交互，`docs/` 为 GitHub Pages 的静态网页。无服务端、无追踪器、无学生数据上传。

## 更新

安装 Node.js 后运行 `npm install`，编辑 Markdown 原稿，再运行 `npm run build`。发布源为 main 分支的 `/docs`，提交更新后的原稿与静态网页即可。

## 内容说明

参考书通过教师提供的合法本地资源阅读核对；仓库不包含商业书籍全文、PDF、扫描页或私人文件。数值算例除另注外为教学材料。各来源的使用范围、具体页码和解释边界见网页“参考文献与阅读指南”。

教学编写版，2026 年 9 月。欢迎通过 Issues 提交有来源的勘误。
