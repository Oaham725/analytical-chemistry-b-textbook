# 绪论

## 1.1 为什么生命科学需要分析化学

在生物学课上，我们会说：植物利用光能合成有机物，细胞通过代谢维持生命，DNA 储存遗传信息，蛋白质参与催化、运输与调节。这些话听起来像关于“生命”的陈述，但支撑它们的证据往往来自非常具体的化学测量：某种气体的消耗量、某个分子的浓度、肽链中的氨基酸顺序、核酸片段的长度，以及荧光在细胞内的位置和变化。

假如两组植物在不同条件下生长，一周后其中一组叶片变黄，我们可以提出很多解释：叶绿素减少了，叶绿体结构改变了，营养元素供应不足，或者组织失水改变了外观。单凭“颜色变浅”不能区分这些解释。我们需要把宽泛的问题变成可以操作的分析任务，例如比较相同叶龄、相同采样时刻的叶片中，单位鲜质量的叶绿素 a 含量。随后还要说明如何取样、如何提取、用什么信号测量以及结果有多可靠。

这个转变包含三层工作。第一层是**概念澄清**：想知道的是叶绿素含量、光合作用速率，还是黄化的原因？第二层是**化学转换**：怎样把叶绿素的性质变成可读出的信号？第三层是**证据判断**：信号差异究竟来自叶绿素，还是来自取样量、提取效率、其他色素或仪器漂移？分析化学不仅负责读出一个数，也负责检验这个数与科学问题之间的联系。

> 本章的核心观点：分析方法不是生物学结论旁边的一段技术说明。它决定了我们能观察到生命过程的哪个侧面，以及结论能够成立到什么程度。

学习本章时，不必急于记住全部仪器名称。更重要的是建立一条始终可以回查的链：**问题 → 被测量 → 样品 → 信号 → 结果 → 解释**。后续的酸碱滴定、络合滴定、光谱、电位分析和色谱，都可以放回这条链中理解。

## 1.2 分析化学的对象、任务与信息层次

分析化学研究和应用获得物质组成、含量、结构、性质及其时空变化信息的方法、仪器和策略。它有两个彼此联系的方面：一方面，对实际样品进行分析，回答具体问题；另一方面，研究新的测量原理、分析方法和质量评价策略，使原来无法获得的信息变得可获得。

**定性分析**回答“是什么”或“是否存在”。但是，检测器出现一个信号并不自动完成定性。还需要根据反应特征、保留行为、光谱或其他证据，把目标物与可能的干扰区分开。**定量分析**回答“有多少”，必须说明量的类型、单位、样品基准及结果可靠性。一个结果写成“蛋白质 5.2”，缺少单位和分母，几乎不能用于比较。

**结构分析**关注原子连接、序列或空间排列。氨基酸组成相同的两条肽链，序列可以不同；序列相同的蛋白质，也可能有不同构象。**形态分析**则关注元素或组分的具体化学存在形式，例如总铁、游离铁和与蛋白质结合的铁并不是同一个被测对象。它们可能具有不同的反应性与生物可利用性。

| 信息层次 | 生命科学中的问题 | 分析结果的解释边界 |
| --- | --- | --- |
| 组成与身份 | 叶片提取物中有哪些色素？ | 检出某成分不说明它位于哪一种细胞结构中 |
| 含量 | 单位鲜质量中有多少叶绿素？ | 含量不直接等于光合速率 |
| 结构与构象 | 蛋白质的序列和折叠怎样？ | 同一序列不保证所有条件下构象相同 |
| 化学形态 | 金属元素以何种价态或结合形式存在？ | 总元素量不能替代形态分布 |
| 空间与动态 | 离子或分子在哪里，何时变化？ | 取样和标记过程可能改变原有状态 |

这些任务不是互不相容的学科抽屉。一项分析常常需要先分离，再定性，再定量；最后结合空间信息和时间信息作出解释。现代生命科学中的复杂研究，通常依靠多种方法相互约束，而不是让一台仪器独自回答所有问题。

## 1.3 四个不能混用的概念：样品、分析物、基质与被测量

**样品（sample）**是实际取得并送入分析流程的材料。它可能是一片叶、一管血清、一份土壤，也可能是经过混合的多个取样单元。**分析物（analyte，亦称待测物）**是我们关注的化学组分，例如叶绿素 a、葡萄糖或铁。**基质（matrix，亦称基体）**是与分析物共存的其他成分；它既可能影响提取和反应，也可能改变检测信号。**被测量（measurand）**则是拟测量的具体量，而不是分析物的名字。[M1](references.html#M1)

“测蛋白质”并没有完整定义被测量。可以测某种蛋白质的物质的量浓度，可以测提取液中总蛋白的质量浓度，也可以测每克叶片鲜质量对应的可溶性蛋白质量。它们的分子、分母、方法和解释范围都不同。写出被测量，是防止一个正确数字被错误使用的最便宜办法。

以叶片分析为例，叶片是样品，叶绿素 a 是分析物，其他色素、脂类和组织成分构成复杂基质；“规定提取方法下，每克鲜叶中的叶绿素 a 质量”才是较清楚的被测量。若换成“每克干叶”，即使分析物总量不变，结果数值也会改变。若研究的是光合作用，则叶绿素含量仍只是相关信息，而不是光合速率本身。

有些被测量还带有明显的**操作定义**。例如“可滴定酸度”取决于滴定条件与终点定义，“可提取态某元素”取决于提取剂和处理程序。这不意味着它们没有价值，而是意味着方法条件属于量的含义。不同程序得到的结果不能只因单位相同就直接等同。

<div class="example"><h4>例 1-1　改写一个模糊的问题</h4><p>原问题：“处理是否使植物的铁增加？”</p><p>可执行的版本：“在相同叶龄与采样时刻，比较处理组和对照组叶片中总铁的质量分数，以干质量为基准；报告独立植株之间的变异。”</p><p>这个改写排除了至少三个歧义：测总铁还是某种结合态；比较浓度还是全株铁总量；以鲜质量还是干质量归一化。它仍不能单独回答铁吸收、运输和利用过程的全部机制。</p></div>

### 从一年级生物学已有知识出发

糖类、脂质、蛋白质和核酸不是四个需要重新背诵的名字，而是选择分析方法的入口。糖类的结构与反应性、脂质在不同介质中的分配、蛋白质的电荷和构象、核酸的碱基组成与互补配对，都能转化为测量或分离的依据。生命体系中还有离子、小分子代谢物和金属配合物；不能因为它们不是“大分子”，就低估其分析意义。[B1](references.html#B1)

| 已经学过的生物化学性质 | 可以提出的分析思路 | 必须防止的过度解释 |
| --- | --- | --- |
| 分子或颗粒的电荷、大小不同 | 电泳、离子交换或尺寸相关分离 | 分离位置不是无需对照的唯一身份证 |
| 组分在不同介质中的溶解与分配不同 | 提取、色谱分离和富集 | 提取得到的部分未必等于样品中的全部 |
| 分子对光的吸收或发射不同 | 光谱检测、显色或荧光探针 | 一个波长的信号可能由多种组分共同贡献 |
| 核酸互补配对或分子识别 | 选择性探针与结合测定 | 识别依赖条件，仍需检查交叉反应与背景 |

Gault 与 McClenaghan 在第 1 章先建立生物分子的组成和性质背景，第 2 章再进入定性、定量和浓度计算。本教材借用这种衔接思路，但不要求先学完生物化学：每遇到一种新方法，先问“它利用的是我已经知道的哪一种分子性质”。[B1](references.html#B1)

## 1.4 分析方法怎样分类，为什么不应只背分类表

按任务可以分为定性、定量、结构和形态等分析；按对象可以分为无机、有机、食品、环境、药物或生物分析；按用途可以分为例行分析和争议复核中的仲裁分析。这些分类回答的是不同问题，因此同一个方法可以同时属于多个类别。分类的价值是帮助选择方法，而不是给方法贴一个唯一标签。

按主要测量依据，课程通常区分**化学分析**和**仪器分析**。重量分析与滴定分析常由反应计量关系把质量或体积转化为待测物含量；仪器分析则常利用光、电、质荷比或其他物理与物理化学性质获得信号。两者没有“是否需要化学原理”的分界。光度分析可能需要显色反应，电位测量依赖电化学平衡，色谱分离也依赖分子间相互作用。

在重量分析中，若待测组分被定量转化为组成确定的称量形式，就可以通过摩尔质量比换算。假设某分析中以 BaSO₄ 作为称量形式，则钡的质量为：

<div class="equation">m(Ba) = m(BaSO₄) × M(Ba) / M(BaSO₄)</div>

公式看似简单，成立条件却并不简单：转化必须充分，称量形式必须已知，沉淀不能含有未处理的夹杂，样品损失和污染应受控制。**计算关系准确，不代表实验已经满足计算关系。**

对滴定反应 aA + bT → 产物，有 n(A)/a = n(T)/b，而 n(T) = c(T)V(T)。因此 n(A) = a·c(T)V(T)/b。这里还须区分理论化学计量点和实际观察的终点。后续滴定章节将讨论，两者的接近程度怎样受平衡、指示体系和操作影响。

光学分析关注吸收、发射或散射等信号；电化学分析关注电位、电流、电导等；色谱利用不同组分在两相之间行为的差异实现分离，再由检测器提供响应。对于复杂生物样品，“先分开再测”往往比单纯提高检测器灵敏度更重要，因为干扰可能与目标物一起产生信号。

### 试样用量与组分含量是两条坐标轴

课程中的常量、半微量、微量和超微量分析，若按**试样用量**分类，描述的是取了多少材料；常量组分、微量组分、痕量组分则描述待测物在材料中占多少。两者不能互相替代。一滴高浓度蛋白溶液属于少量样品，但蛋白并不因此成为痕量组分。

| 按试样用量的课程约定 | 固体试样 | 液体试样 |
| --- | --- | --- |
| 常量 | 大于 0.1 g | 大于 10 mL |
| 半微量 | 0.01–0.1 g | 1–10 mL |
| 微量 | 0.1–10 mg | 0.01–1 mL |
| 超微量 | 小于 0.1 mg | 小于 0.01 mL |

按组分质量分数，本课程沿用常量组分大于 1%、微量组分约 0.01%–1%、痕量组分约 10⁻⁴%–0.01%、超痕量组分小于 10⁻⁴% 的约定。分级阈值不是自然常数，不同资料可能有不同约定，边界归属应以所用教材或标准为准。实际报告中，写出具体取样量与浓度，通常比只写“痕量分析”更清楚。

## 1.5 量、单位与浓度：先把分母说清楚

对于定量分析，“有多少”必须落实为一个量。质量、体积、物质的量与浓度之间可以转换，但转换所需的信息并不总是齐全。一个常见错误是把含有相同数字的不同表达视为同一个量，例如把 1% 与 10 mg/mL 无条件等同。

**质量分数** w(B) = m(B)/m(样品)，是两个质量之比，因此无量纲，可以用百分数或带有明确质量比意义的 mg/g 表示。**质量浓度** γ(B) = m(B)/V(溶液)，常用 g/L、mg/L。**物质的量浓度** c(B) = n(B)/V(溶液)，常用 mol/L。三者的分母并不相同。已知摩尔质量 M(B) 时，γ(B) = c(B)M(B)；若还知道溶液密度 ρ，则 w(B) = γ(B)/ρ，但单位必须一致。

**质量摩尔浓度** b(B) = n(B)/m(溶剂)，常用 mol/kg，分母是溶剂质量，不是溶液质量。**摩尔分数** x(B) = n(B)/Σn(i)，描述组成中的物质的量比例。**体积分数**通常依据混合前各组分体积定义；由于液体混合后体积未必可加，实验配方中的“%（v/v）”还应说明具体配制方式。

<div class="example"><h4>例 1-2　0.90 g NaCl 定容至 100 mL</h4><p>已知最终溶液体积为 0.100 L，质量浓度 γ = 0.90/0.100 = 9.0 g/L。取 M(NaCl) = 58.44 g/mol，物质的量浓度约为 0.15 mol/L。</p><p>能否直接说质量分数为 0.90%？不能仅由这些信息严格推出。质量分数的分母是溶液质量，而题目只给出了体积。若使用密度近似，必须明确这是额外假设。</p></div>

**稀释关系**来自待测物总量守恒，而不是来自“浓度公式的口诀”。若转移体积 V₁ 的原液并定容到 V₂，在无损失、无反应且浓度定义一致的条件下，有 c₁V₁ = c₂V₂。稀释倍数 D = V₂/V₁。连续两次稀释的总倍数等于各倍数之积，但每一步移液与定容也会带入不确定度。

本教材统一用 D = V₂/V₁ = c₁/c₂ 表示稀释倍数；真正稀释时 D > 1、c₂ < c₁。若使用“稀释分数”，则另记 f = 1/D。这个符号约定有助于避免不同资料把“稀释因子”分别写成 20 和 1/20 的歧义。浓度为零等特殊情况不使用浓度之比定义。

另一个常见歧义是 ppm。若明确定义为质量比，1 ppm = 1 mg/kg；只有在稀水溶液密度可近似取 1 kg/L 等条件下，才可把其数值近似对应为 1 mg/L。分析报告最好直接写明所用的量和单位，不让一个缩写隐藏密度假设。

结果还可能按某种化学形式约定表达。总磷“以 P 计”与“以 P₂O₅ 计”可以按组成关系换算，但后者并不证明样品中实际存在 P₂O₅。同样，“每毫升培养液”“每克鲜叶”“每克干叶”“每个细胞”回答不同问题。归一化可以使比较有意义，也可能引入新的假设：细胞数的计数误差、含水量的变化或总蛋白本身的变化，都可能改变比值。

> 检查任何浓度或含量结果时，依次读出：分子是什么，分母是什么，单位是什么，化学形式是什么，样品基准是什么。数字最后再读。

## 1.6 取样：仪器之前，证据已经开始形成

如果要研究一个培养体系、一个地块或一批产品，我们通常无法测量其中每一个部分。取样是在有限测量与目标总体之间建立联系。因此，取样不是分析开始前的杂务，而是分析推断的一部分。重复测量同一份缺乏代表性的试样，可以把那个试样测得更稳定，却不能让它代表整个总体。

可以把取样层级理解为：研究对象总体 → 选中的取样单元 → 份样 → 按计划合并的总样 → 缩分后的实验室样品 → 制备后的试样 → 实际进入一次测定的试料。这里的每一次合并或减少，都可能改变能保留的信息。混合多株植物可以得到某个平均组成的样品，却也会抹去植株之间的变异；混合后再分成三管，不会重新创造三个独立的生物学重复。

**随机化**帮助避免选择偏向；**独立重复**使研究能够评价相关层级的变异；**分层或区组**则可以在已知环境差异存在时改善比较。它们都要围绕研究问题来设计。测同一批组织提取液的重复性，与比较独立植株的处理效应，要求的样本层级不同。[B3](references.html#B3)

生物样品尤其需要明确时间。取下叶片以后，代谢、氧化、酶反应、吸附或挥发未必立刻停止。于是“采样时的组成”和“测量时的组成”可能不同。要测的是稳定的元素总量，还是变化很快的代谢物？要保存结构，还是只保存某元素？这些问题决定采集、运输和保存方案。具体条件必须由经过验证的方法决定，而不是凭一个通用“低温保存”口号。

<div class="example"><h4>例 1-3　哪一种重复能回答处理效应？</h4><p>方案 A：只取一株处理植物和一株对照植物，各测十次。方案 B：每组取六株独立处理植物，每株测两次。若研究对象是植株层面的处理效应，方案 B 提供更多相关层级的独立信息。A 的十次读数主要帮助认识技术波动，不能弥补每组只有一株的设计。</p></div>

## 1.7 前处理：保留什么，牺牲什么

前处理的目标不是把所有样品都变成“澄清溶液”，而是将样品转化为适合测量的形式，同时保留目标信息。**溶解**使可溶组分进入溶液；**提取**利用目标物在介质中的行为将其转移出来；**消解**常通过破坏有机基质，为元素总量分析创造条件；**熔融**可用于某些难溶无机材料。这些手段保留和破坏的信息不同。

测组织中的总铁时，破坏有机结构可能是必要步骤；但若想知道铁原来与哪些蛋白质结合，同样的消解就会破坏所需信息。测蛋白质总量、测特定蛋白质、测酶活性，也不能默认使用同一种提取程序。改变 pH、离子强度或有机溶剂比例，既可能改善溶出，也可能改变构象、反应活性与检测响应。

处理干扰的思路主要有三类。**掩蔽**改变干扰物的化学行为，使其不再明显影响目标反应，但不一定将它移走；**分离**利用性质差异把组分分开；**富集**提高目标物的相对浓度或单位测量体积中的量。富集也可能同时富集干扰物，或者因为容器吸附与洗脱不完全造成损失。

“回收率高”是有价值的信息，却不自动证明全部前处理正确。向已经提取好的溶液中加标，只检查加标以后那部分过程；向原始样品加标，虽然覆盖更多步骤，加入的游离目标物也可能与样品中原有结合态目标物行为不同。应说明加标位置、形式、水平和计算方式，而不是只报告一个百分数。[M4](references.html#M4)

## 1.8 校准、空白与质量控制：每一种参照在问什么

校准建立示值或信号与已知量值之间的关系。在线性模型 y = a + bc 中，y 是信号，c 是浓度，a 是截距，b 是斜率。未知样的信号 yᵤ 经反算得到 cᵤ = (yᵤ − a)/b。截距有无统计或物理依据需要分析，不能因为“零浓度就该零信号”而任意强制过原点。

**标准系列**用于建立关系；**空白**用于检查无目标物条件下的背景、试剂或容器污染；**质控样**用于核查分析过程的表现；**参考物质**提供可比较的性质或量值。它们的角色可以有关联，但不能互相替代。把拟合所用的同一批标准点重新代入公式，只能有限地检查拟合本身，不能作为完全独立的验证。

空白也有层次。只测溶剂，不能排除消解试剂的污染；经过全部步骤的程序空白更接近完整过程，却仍不能复制真实样品的基质。需要选择与问题匹配的空白，而不是追求一个抽象的“零信号”。

**标准方法**规定取样、处理、测量或评价程序；**有证标准物质**则在相应证书中提供指定量值、不确定度和计量溯源等信息。使用标准方法仍应检查适用对象与范围。将适用于清洁水样的方法搬到蛋白质丰富的培养液，并不自动保证性能不变。[M1](references.html#M1)

<div class="chain"><span>标准系列：建立关系</span><b>＋</b><span>空白：检查背景</span><b>＋</b><span>质控样：核查过程</span><b>→</b><span>带有可靠性说明的结果</span></div>

计量溯源并不是“仪器来自著名厂商”，而是量值通过有记录的校准链与参考相联系，并考虑链中各环节的不确定度。对于初学者，至少应养成问三个问题的习惯：标准从哪里来？标准的量值怎样确定？从标准到样品是否经历了可解释的转换？

## 1.9 方法性能：灵敏不等于准确，检出不等于定量

**精密度**关注规定条件下重复结果彼此有多接近。重复条件可以是同一操作者、同一设备、短时间内，也可以扩展到不同日期、人员或实验室。因此，说一个方法“精密”时，还应说明评价的条件。**准确度**关注与真值的接近程度；实践中常用有适当依据的参考量值评价。有限实验中观察到的均值与参考值差别，可以作为偏倚的估计，但还包含抽样波动与参考值自身的不确定性。[M1](references.html#M1)

**灵敏度**描述输入量变化时响应变化有多大。在线性校准中，灵敏度对应斜率 b，其单位取决于信号和浓度单位。**选择性**关注共存组分对测定的影响，以及能否在给定条件下将目标物的响应与干扰区分。斜率很大的方法，若空白波动也很大或干扰严重，不一定具有更好的低浓度测量能力。

**检出限（LOD）**涉及在规定判据下区分目标存在与背景的能力；**定量限（LOQ）**涉及满足预设质量要求的最低定量水平。在一些近似线性、噪声条件明确的处理中，常见 LOD ≈ 3σ₀/b、LOQ ≈ 10σ₀/b，其中 σ₀ 表示低水平或空白响应波动的适当估计。但这些系数不是对所有方法通用的自然常数，实际估算与验证应说明判据及实验设计。[M4](references.html#M4)

“未检出”不等于“绝对不存在”；“有一个小峰”也不等于“可以给出可靠含量”。如果结果落在可靠定量范围以下，应按方法规定表达限制，而不是随意补出多个小数位。第二章将进一步讨论为什么数字格式不能提升证据质量。

**工作范围**是方法达到预定要求的范围；**线性范围**是线性关系足够适用的区间；**动态范围**常用可用响应上下限的跨度描述，可以包含非线性部分。高相关系数不等于宽工作范围，线性拟合良好也不证明高浓度未知样可以任意外推。

方法评价还应考虑速度、自动化、样品消耗、费用和安全。原课件中的“3S 与 2A”可以作为记忆线索：Sensitivity、Selectivity、Speed、Accuracy、Automation。但选择方法的顺序应是先写清分析任务和质量要求，再权衡性能，而不是先挑最贵或最新的设备。

## 1.10 分析花絮一：从“测氮”到“蛋白质”的距离

19 世纪末，Kjeldahl 在研究有机物和原料的氮含量时发展了定氮方法。这项工作与实际工业分析需求密切相关，也成为理解食品和生物材料中含氮组分的重要工具。[H1](references.html#H1)

课堂上最值得讨论的，不是记住方法名称，而是追问：**测到氮，为什么有人会报告蛋白质？**如果假定目标蛋白质平均含氮质量分数为 16%，则蛋白质质量约等于氮质量除以 0.16，也就是乘以 6.25。这是一个换算模型。模型暗含“相关氮主要来自蛋白质”和“平均含氮比例适用”等条件；核酸、游离氨基酸及其他含氮物质会使问题更复杂，不同材料也未必适合统一换算因子。[B4](references.html#B4)

<div class="example"><h4>例 1-4　一个模型的数值与含义</h4><p>若教学样品测得氮质量分数为 2.00%，采用约定因子 6.25，则粗蛋白估计为 12.5%。这里“粗蛋白”是依据氮含量与换算约定得到的结果，不是已经逐一识别并称量了所有蛋白分子。</p><p>如果样品中非蛋白氮增加，氮测定可能完全正确，而“蛋白质增加”的解释仍可能错误。错误并不一定出在仪器，也可能出在从被测量通往目标概念的那一步。</p></div>

这一案例可以连接到一年级生物学中的“生物大分子的元素组成”。蛋白质、核酸和代谢物共享某些元素，元素总量并不具有分子身份的唯一性。分析化学要求我们区分**直接获得的信息**与**通过模型换算的信息**。这种区分在现代组学和 AI 中依然重要：一个代理指标可以有用，但必须说明它与目标之间的关系和限制。

## 1.11 分析花絮二：胰岛素——从组成、顺序到含量

蛋白质并不是“由若干种氨基酸混在一起”的物质。氨基酸的排列顺序同样构成信息。Sanger 关于胰岛素结构的工作体现了一种非常重要的分析思路：将复杂对象转化为更小的可分析片段，通过分离、鉴定与重叠关系重建整体。其诺贝尔演讲可以作为进入这段历史的原始讲述。[H2](references.html#H2)

这里需要区分“组成”和“序列”。假设两条教学肽链分别为 Ala–Gly–Ser 和 Ser–Ala–Gly，它们含有完全相同的三种氨基酸，组成比例相同，顺序却不同。只做完全水解后的氨基酸组成分析，就会失去排列信息。由此可以理解，前处理不是越彻底越好：它必须与信息目标一致。

胰岛素还引出另一条分析路线。Yalow 与 Berson 在 1960 年发表内源性血浆胰岛素的免疫测定研究，将分子识别用于微量激素定量。这样的问题不是“胰岛素的序列是什么”，而是“样品中的胰岛素有多少，以及它怎样随实验条件改变”。[H3](references.html#H3)

免疫识别并不意味着没有分析问题。识别对象、校准物、交叉反应和样品基质都影响结果。更进一步，激素浓度与激素作用也不是同一个量。浓度变化可以与生理反应相联系，但从浓度走向作用机制，仍需要受体、信号通路和实验设计方面的证据。

> 生物学连接：同一个分子可以提出组成、序列、构象、含量和功能等不同问题。方法选择要跟随问题，而不能因为都叫“测蛋白质”就认为答案可以互换。

## 1.12 分析花絮三：DNA 复制模型怎样被区分

“DNA 半保留复制”是生物学中的熟悉结论。对分析化学而言，更重要的问题是：怎样设计测量，使不同复制模型产生可以区分的结果？Meselson 与 Stahl 的经典研究利用同位素标记与密度梯度分离，把分子来源的差别转化为可观察的密度差别。[H4](references.html#H4)

在理想化课堂模型中，先使 DNA 带有较重的氮同位素标记，再转入轻同位素培养条件。如果复制采用全保留方式，第一代应同时出现保持重标记的旧双链和新的轻双链；如果采用半保留方式，第一代应主要形成一条旧链配一条新链的中间密度分子。分散复制模型也可能在第一代产生中间密度，因此只看一代并不足以排除所有替代解释。后续代数的分布变化继续提供区分证据。[H4](references.html#H4)

| 理想模型 | 转入轻标记条件后的第一代 | 继续复制后的关键差别 |
| --- | --- | --- |
| 全保留 | 重、轻两类双链 | 重双链作为整体保留 |
| 半保留 | 主要为中间密度双链 | 可出现轻与中间密度两类 |
| 分散 | 每条链混有新旧片段 | 理想化预测为标记逐渐稀释的混合状态 |

表格是帮助比较模型的教学简化，不复现原实验所有条件。它说明“看到中间条带”不是最终推理的全部；观察结果必须放到不同模型的预测中比较。分析方法的强项，在于将肉眼不可区分的分子差别变成可比较信号，并通过恰当对照排除替代解释。

这一逻辑可迁移到生物实验设计：如果两个机制对你测的变量给出相同预测，再精密地测这个变量，也不容易区分机制。此时需要增加信息维度，例如时间、空间、另一种分子标记或独立方法，而不是只增加小数位。

## 1.13 分析花絮四：颜色、光与分子识别

Bradford 在 1976 年提出的蛋白质—染料结合定量方法，是初学者认识“把化学行为转成信号”的典型入口。它帮助我们把蛋白质相关的显色响应转化为含量信息，但定量仍依赖校准和适当条件。[H5](references.html#H5)

颜色不是浓度本身。光与样品相互作用后，检测器获得响应；这个响应可能包含目标物贡献、共存物贡献以及背景。以简单线性教学校准 A = 0.010 + 0.600c 为例，A 为吸光度，c 的单位为 mg/mL。若未知样 A = 0.310，则在校准关系适用的条件下，c = (0.310 − 0.010)/0.600 = 0.500 mg/mL。未知样还必须处于经确认的测量范围内。

校准物和待测样不是一回事。用一种参考蛋白建立曲线时，最终结果反映的是在该方法与校准条件下的定量关系。不能自动把这种总量结果解释为某种特定蛋白的含量，也不能从含量直接推断酶活性。后者还需要功能测定及其条件。

分子识别则提供另一种把“是否结合”变成信号的途径。抗原—抗体识别、核酸互补配对等，可以参与设计选择性分析。以分子信标为例，特定核酸探针的构象变化可以改变荧光团与猝灭团的距离，从而改变荧光；它把序列互补关系与光学信号联系起来。[H6](references.html#H6) 但有信号不等于已经排除了所有非特异作用，定量也需要背景、识别条件与校准的核查。

从这里回看分析化学的理论基础，就会发现溶液平衡、分子结构、光与物质相互作用、反应动力学和统计处理不是孤立章节。它们共同回答：信号为什么产生，什么时候只反映目标，怎样把它转化为可信的结果。

## 1.14 贯穿案例：为叶片黄化建立一条可复核的分析链

现在把前面各节组合起来。研究者希望比较一种处理是否改变叶片色素含量。首先，应把“变黄”分解为较明确的分析任务；如果本次只测叶绿素含量，就不能把研究目标写成已经证明了黄化机制。

**第一步，定义与设计。**预先规定叶位、叶龄、采样时刻、取样单元和结果基准。每组使用若干独立处理植株；如还要比较技术精密度，可以在每株样品内部安排复测，但记录清楚层级。设定对照，并在条件允许时随机安排处理和测量次序。

**第二步，取样与前处理。**选择适合目标色素的采集、保存、提取和分离方法，记录实际称样量、体积、稀释步骤及异常情况。这里不提供通用实验配方，因为溶剂、光照和温度条件应由具体经验证的方法确定。重要的是知道每一步要保护的是什么信息，以及可能造成何种损失。

**第三步，测量与质控。**在适用范围内建立校准或使用经过论证的测量关系，设置适当空白与独立质控。若共存组分产生重叠响应，可能需要改进分离或模型，不能仅靠重复读取同一信号解决。

**第四步，换算回样品。**假设教学校准给出检测溶液中目标物质量浓度 γ = 2.0 mg/L；对应提取液总体积 V = 0.025 L；叶片鲜质量 m = 0.50 g，且本例没有额外稀释。则目标物质量为 γV = 0.050 mg，单位鲜质量的含量为：

<div class="equation">q = γV / m = (2.0 mg/L × 0.025 L) / 0.50 g = 0.10 mg/g</div>

如果检测前稀释 D 倍，则 q = γVD/m。注意 γ 应明确对应“检测液”还是“原提取液”，否则稀释倍数容易漏乘或重复乘。计算中单位相消可以帮助发现错误，但单位正确还不能保证模型条件成立。

**第五步，评价与解释。**按独立实验单位汇总数据，报告含量差异及变异，说明结果基准、测定条件和质量控制。在此基础上，可以讨论处理与叶绿素含量的关系。若要进一步解释光合功能或黄化机制，需要与其他生物学证据结合。

## 1.15 元知识：观察、模型与解释的三道边界

**第一道边界是从样品到信号。**任何仪器都只能观察样品的某些性质。检测器记录的不是“生命活力”或“健康程度”，而是可定义的响应。信号与目标信息的关系，需要化学选择性、分离、识别或实验设计来保证。

**第二道边界是从信号到量值。**校准、空白扣除、稀释换算和归一化都属于模型。模型不是坏东西；没有模型，我们难以把示值解释为量。但是模型必须有适用条件，参数必须有来源，计算必须能够复核。

**第三道边界是从量值到生物学解释。**浓度差异可能来自生成、消耗、运输、体积变化或样品处理。即使某个差异统计上清楚，也不意味着机制已经唯一确定。相关、预测和因果是不同层级的主张。

这三道边界还解释了为什么透明记录如此重要。科学结论需要让别人有机会检查“还有什么解释”。原始数据、操作记录、代码和样品信息不是结果之外的附件，而是重建证据链的条件。遇到与预期不一致的数据，应先调查过程和假设，而不是先修改数字。

> 一项好的分析，应让另一个人能够复述：样品代表谁，测的是什么，怎样得到结果，哪些条件支持结论，哪些问题尚未回答。
